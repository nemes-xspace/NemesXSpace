# ADR-000: Kayıt Sözleşmesi

- Yer: `docs/ADR/NNN-kisa-ad.md`. Numara tekil-artan.
- Başlıklar: Tarih, Statü (öneri/kabul/ret/yerine-geçti), Bağlam, Karar,
  Gerekçe, Alternatifler (+ret nedeni), Sonuçlar, Geri-dönüş.
- Değişiklik: yeni sürüm dosyası YASAK üzerine-yazma; statü güncellenir,
  eski korunur. Onay: şifre sahibi onayı (tarihli ibare).
